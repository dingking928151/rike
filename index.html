AI 智能体

本地智能体桥未连接

让 Claude Code / kimi 这类 PC 端 AI 智能体读写你的日课：在 rike 仓库运行 node agent/rike-mcp.js 保持不动，另执行 claude mcp add rike -- node agent/rike-mcp.js； 然后对它说「看看我今天有什么安排」「帮我记 40 分钟专注」。本页开着时自动连接；桥只监听本机 127.0.0.1，数据不出这台电脑。

手机联动：改为运行 node agent/rike-mcp.js --lan， 手机浏览器打开控制台里打印的地址，输入 6 位配对码即成——手机和电脑用同一份数据，手机上加的日程电脑立刻可见。
